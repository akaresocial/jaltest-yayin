# jaltesttr.com — yayın deposu

Bu depo **yalnızca derlenmiş siteyi** (`public/`) ve yayın betiklerini (`_ops/`) içerir. Kaynak kod özel depodadır.
Otomatik üretilir: `.github/workflows/yayin.yml` siteyi derler, imzalar ve buraya gönderir; sunucu buradan kurar.

Bu depoda şifre, ödeme anahtarı, müşteri/sipariş verisi, banka bilgisi ya da üretici görseli **bulunmaz**.
